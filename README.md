# 🚀 FocuX – All-in-One Productivity Dashboard

**FocusX** is a modern productivity dashboard built with **HTML, SCSS, and Vanilla JavaScript**. It brings together essential productivity tools into a single, responsive interface to help users stay organized, focused, and motivated throughout the day.

---

## ✨ Features

### ✅ Todo Manager
- Create, update, and delete tasks
- Mark tasks as important
- Mark tasks as completed
- Persistent storage using LocalStorage

### 📅 Daily Planner
- Hourly planner from **6:00 AM – 12:00 AM**
- Automatically saves plans
- Restore plans on page refresh
- Clear all plans with one click

### 🎯 Goals Tracker
- Add and remove daily goals
- Mark goals as completed
- Circular progress indicator
- Track completed vs total goals
- Data persistence with LocalStorage

### 🍅 Pomodoro Timer
- 25-minute focus timer
- Start, Pause, Resume, and Reset functionality
- Simple state management
- Dynamic button states

### 💬 Daily Motivation
- Fetches inspirational quotes from a public API
- Generate a new quote instantly
- Stores the latest quote locally

### 🌤️ Live Weather
- Detects user's current location
- Displays:
  - Temperature
  - Weather Condition
  - Current City
- Uses browser Geolocation API

### 🕒 Real-Time Dashboard
- Live Clock
- Current Date
- Day of the Week
- Month and Year

### 🎥 Dynamic Wallpapers
- Automatically changes background video based on time:
  - 🌅 Morning
  - ☀️ Afternoon
  - 🌇 Evening
  - 🌙 Night

### 🌗 Theme Toggle
- Light Mode
- Dark Mode

### 📱 Responsive Design
- Optimized for:
  - Desktop
  - Tablet
  - Mobile
